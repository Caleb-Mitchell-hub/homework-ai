面试题 AI 评分 & 笔记 — 整体架构

方案 A：渐进式增强，在现有架构上扩展三个模块

系统架构概览
┌─────────────────────────────────────────────────────────┐
│                    答题页面 (quiz/[id])                    │
│  QuestionCard → 面试题 textarea → 提交 → 评分进度条        │
│  ┌─ 侧边笔记面板 (新增) ─────────────────────────────┐    │
│  │  题目笔记 | 答题笔记 | 快速保存                     │    │
└─────────────────────────────────────────────────────────┘
          │                        │
          ▼                        ▼
┌─────────────────┐     ┌──────────────────────────┐
│  POST /api/results │     │  POST /api/notes (新增)   │
│  提交时触发AI逐题  │     │  题目笔记 / 答题笔记 CRUD    │
│  打分 (0-100分)   │     └──────────────────────────┘
└────────┬────────┘
         │
         ▼
┌─────────────────────────────────────────────────────┐
│              面试题 AI 评分服务 (扩展)                  │
│  gradeOneQuestion() → 新增 0-100 分制打分            │
│  输出: { score, comment, strengths, weaknesses }     │
└────────┬────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────┐
│              面试题 AI 报告 (新增)                     │
│  POST /api/ai/interview-report → 100积分/次           │
│  逐题打分汇总 + 整体评分 + 薄弱点详细分析 + 建议       │
└─────────────────────────────────────────────────────┘

数据模型新增:
  • ResultItem 扩展: interviewScore, interviewFeedback
  • Note 模型: userId, quizId, questionId, type, content
  • CreditReason 新增: ai_interview_report

三个模块

1

AI 逐题评分

提交时自动触发，每题 0-100 分，带进度提示

2

面试题深度报告

100 积分/次，逐题分析 + 整体评价 + 薄弱点详解

3

笔记功能

题目笔记 + 答题笔记，侧边面板 + 独立管理页
