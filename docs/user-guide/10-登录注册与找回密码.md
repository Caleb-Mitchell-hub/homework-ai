# 登录注册与找回密码

## 功能说明

本系统提供三种身份进入方式：**账号密码登录**、**注册新账号**、**游客匿名进入**。登录后可访问全部功能，游客可浏览题库和答题但部分功能受限。注册时会进行用户名实时查重，注册完成后需设置密保问题和职业方向。忘记密码时通过密保问题验证身份后重置密码。

## 一、账号密码登录

### 表单字段

默认进入页面即为登录模式。表单包含以下字段（从上到下）：

#### 1. 用户名输入框

- 标签：**"用户名"**
- placeholder：`输入用户名`
- 样式：浅灰背景（`bg-slate-50`），圆角边框（`rounded-xl`），宽 100%
- 聚焦时边框变为天蓝色（`border-sky-400`），外圈有淡蓝色光晕（`ring-4 ring-sky-100`）

#### 2. 密码输入框

- 标签：**"密码"**
- placeholder：`输入密码`
- 右侧有一个**眼睛图标按钮**：
  - 默认状态为**闭眼图标**（斜线划过眼睛），密码以圆点（`••••`）显示
  - 点击后切换为**睁眼图标**，密码以明文显示
  - 再次点击切回隐藏状态
  - 按钮 hover 时图标颜色变蓝
- 支持按 **Enter 键**直接触发登录
- 样式与用户名输入框相同

#### 3. 记住密码 + 忘记密码

密码框下方同一行，左右分布：

**左侧——记住密码**：
- 一个**自定义复选框**（18px 方形，圆角 `rounded-md`）：
  - 未选中：灰色边框（`border-slate-300`），白色背景，鼠标悬停时边框变蓝
  - 选中：蓝绿渐变背景，边框变透明，内部显示白色✓图标
- 复选框右侧文字"**记住密码**"（灰色，hover 时变深）
- 点击文字也可切换复选框状态

**右侧——忘记密码**：
- 蓝色文字链接"**忘记密码？**"（`text-sky-500`），hover 时颜色加深
- 点击跳转到 `/forgot-password` 页面（找回密码流程，详见后文）

#### 4. 登录按钮

- 蓝绿渐变全宽按钮（天蓝 → 蓝色），白色文字"**登录**"
- 加载中状态：按钮文字变为旋转圈图标 + "处理中..."，按钮半透明不可点击
- 正常状态有 hover 放大效果（`scale-[1.02]`），点击有按下缩小效果（`active:scale-[0.98]`）
- 有轻微天蓝色阴影（`shadow-lg shadow-sky-200`）

#### 5. 底部提示

- 灰色文字"还没有账号？" + 蓝色链接"**立即注册**"
- 点击"立即注册"切换到注册模式

### 记住密码功能

**勾选"记住密码"后的行为**：
- 登录成功后，将用户名、密码、记住标记（`remember_flag: '1'`）存入浏览器 `localStorage`
- 下次进入登录页时自动：
  - 填入已保存的用户名和密码
  - 勾选"记住密码"复选框

**取消勾选"记住密码"**：
- 清除 `localStorage` 中的记住信息
- 不影响已登录状态

**注意**：密码以明文形式存储在 `localStorage` 中，仅建议在个人设备上使用此功能。

### 登录流程

1. 输入用户名和密码
2. 点击"登录"按钮或按 Enter 键
3. 系统调用 `POST /api/auth/login`
4. **成功**：
   - 如勾选了"记住密码"，保存凭证至 `localStorage`；否则清除已保存的凭证
   - 调用 `login(data.token, data.user)` 将登录态存入 AuthContext
   - 页面跳转至首页 `/`
5. **失败**：
   - 在表单下方显示红色错误卡片（`bg-rose-50`，红色边框 `border-rose-200`）
   - 卡片左侧有圆形感叹号图标，右侧显示错误信息文字（如"用户名或密码错误"、"网络错误"等）
   - 错误卡片带有**水平抖动动画**（左右晃动 `shake`，持续 0.5 秒）

## 二、注册新账号

### 进入注册模式

点击卡片顶部的"注册"标签，表单切换到注册模式。

### 注册模式下的变化

相比登录模式，注册模式有以下不同：

1. **用户名输入框增加实时查重功能**（详见下方）
2. **密码框下方增加"确认密码"输入框**
3. **不显示"记住密码 / 忘记密码"行**
4. **登录按钮文字变为"注册"**，颜色仍为蓝绿渐变
5. **底部提示文字变化**："已有账号？立即登录"（点击切回登录模式）

### 用户名实时查重

注册模式下，输入用户名后系统自动进行实时查重：

**触发条件**：用户名长度在 3~20 个字符之间（不足 3 或超过 20 不触发查重）。

**防抖机制**：输入停止 **500ms** 后自动发起查重请求。

**三种状态及对应 UI**：

| 状态 | 边框颜色 | 右侧图标 | 额外提示 |
|------|----------|----------|----------|
| **查重中** (checking) | 灰色默认 | 旋转圈图标（`animate-spin`） | 无 |
| **可用** (available) | **绿色** (`border-emerald-300`) | **绿色✓图标** | 输入框下方绿色小字"✓ 该用户名可用" |
| **已被使用** (taken) | **红色** (`border-rose-300`) | **红色✗图标** | 输入框下方弹出红色提示框 |

**已被使用时的提示框**：
- 浅红背景（`bg-rose-50`）+ 红色边框（`border-rose-200`）
- 顶部一行：警告图标 + "该用户名已被使用，请重新命名或使用系统推荐："
- 下方有**系统推荐用户名**标签（白色背景、红色边框、红色文字的小按钮）：
  - 点击推荐用户名标签 → 自动填入该用户名
  - 如果没有推荐 → 显示灰色文字"暂无可用推荐，请手动换一个名字。"

### 确认密码

确认密码输入框位于密码输入框下方，样式与密码框相同。

**实时对比校验**：
- 输入后实时与"密码"字段对比（不区分显示/隐藏状态）

| 状态 | 边框颜色 | 右侧图标 | 下方提示 |
|------|----------|----------|----------|
| 不一致 | **红色** (`border-rose-300`) | **红色✗图标** | 红色文字"两次输入的密码不一致" |
| 一致 | **绿色** (`border-emerald-300`) | **绿色✓图标** | 无 |

无输入时显示默认灰色边框。

### 注册流程

1. 输入用户名（等待查重状态变为"可用"，即绿色✓）
2. 输入密码（至少 6 位）
3. 再次输入确认密码（等待一致性校验通过，即绿色✓）
4. 点击"注册"按钮或按 Enter 键

**前端校验**（任一不通过则显示红色错误提示，不发出请求）：
- 用户名不能为空
- 密码不能为空
- 密码长度不能少于 6 位
- 两次输入的密码必须一致

**后端请求**：`POST /api/auth/register`，发送 `{ username, password }`

**成功**：
- 自动调用登录接口 `POST /api/auth/login` 获取 token
- 调用 `login(data.token, data.user)` 存入 AuthContext
- 如果勾选了"记住密码"，同时保存凭证至 `localStorage`
- 页面跳转至 `/register/setup`（完善账户信息页面）

**失败**：
- 显示红色错误卡片（与登录模式相同），显示后端返回的错误信息（如"用户名已存在"等）

## 三、游客模式

### 进入游客模式

点击卡片顶部的"游客"标签。

**页面变化**：
- 登录/注册表单以 translate 动画滑出并隐藏（`overflow-hidden`）
- 登录按钮变为**绿色渐变**（翠绿 → 青色，`from-emerald-400 to-teal-400`），文字变为"**匿名进入**"
- 绿色按钮有翠绿色阴影，hover 效果与登录按钮一致

### 游客登录流程

1. 点击"匿名进入"按钮
2. 系统调用 `POST /api/auth/guest`
3. 成功：
   - 自动登录，跳转首页 `/`
   - 游客用户可以浏览题库、进行答题
   - 游客的职业选择可在首页顶部设置
4. 失败：
   - 显示红色错误卡片

**注意**：游客用户部分功能受限（如创建题库、AI 解析等可能需要登录权限）。

- 副标题"设置密保问题保护您的账户，选择职业获得更好的体验"

### 表单字段

#### 密保问题

- 区域标题带锁图标 + "密保设置 · 忘记密码时使用"

**安全问题**（下拉选择框）：
- 样式：浅灰背景，圆角边框，右侧有向下箭头图标
- 预设问题列表：

| 序号 | 问题 |
|------|------|

**问题答案**（文本输入框）：
- placeholder：`请输入答案（不区分大小写）`
- 按 Enter 键可直接触发"完成设置"

#### 职业选择（可选）

- 标签："职业选择 （可选）"
- 下拉选择框，选项从服务端获取：

**"完成设置"按钮**：

- 调用 `POST /api/auth/setup`，发送 `{ securityQuestion, securityAnswer, professionId }`
- 成功后跳转首页 `/`
- 失败显示红色错误提示卡片

**"暂时跳过，稍后设置"链接**：
- 灰色小字链接，位于按钮下方居中
- 如果选了职业，会先调用 `PATCH /api/user/profession` 更新职业，然后跳转首页
- 如果没选职业，直接跳转首页
- 点击后文字变为"跳转中..."

### 页面保护

- 未登录用户访问此页面会自动跳转到 `/login`。
- 页面加载中显示居中旋转圈动画。

## 五、找回密码

忘记密码时可通过密保问题验证身份后重置密码。访问路径：`/forgot-password`，也可从登录页的"忘记密码？"链接进入。

### 页面布局

- 居中卡片布局，蓝绿渐变背景 + 装饰光晕
- 顶部居中：Logo（钥匙 SVG 图标，蓝绿渐变圆角方块）+ 右侧"找回密码"标题 + 副标题"通过密保问题验证身份"
- **步骤指示器**：3 个横向圆角横条，依次表示当前进度：

| 横条状态 | 样式 |
|----------|------|
| 已完成的步骤 | 蓝色实心，窄条（`w-8 bg-sky-400`） |
| 当前步骤 | 蓝绿渐变，加长（`w-12`，`from-sky-400 to-emerald-400`） |
| 未完成的步骤 | 灰色实心，窄条（`w-8 bg-slate-200`） |

- 下方为白色半透明卡片（`backdrop-blur-xl`，圆角 3xl）

### 第一步：验证账号

**界面内容**：
- 标题："**第一步：验证账号**"
- 说明文字："输入您要找回的账号的用户名"
- 用户名输入框（自动聚焦），placeholder `输入用户名`
- 按 Enter 键触发"下一步"

**操作**：
1. 输入要找回密码的账号用户名
2. 点击"下一步"按钮或按 Enter

**后端请求**：`POST /api/auth/forgot-password`，发送 `{ step: 'get_question', username }`

**成功**：
- 获取该用户预设的密保问题文字
- 自动进入第二步

**失败**：
- 显示红色错误提示框（浅红背景 + 红色边框 + 感叹号图标 + 错误文字）
- 常见错误：用户不存在、该账号未设置密保问题等

### 第二步：回答密保问题

**界面内容**：
- 标题："**第二步：回答密保问题**"
- 说明文字："请回答账号「**xxx**」的密保问题"（账号名加粗显示）
- **密保问题卡片**：浅蓝背景（`bg-sky-50`）+ 蓝色边框（`border-sky-200`），内部上方小字"安全问题"（蓝色大写），下方显示具体问题文字（加粗）
- 答案输入框（自动聚焦），placeholder `输入当时设置的答案(不区分大小写)`
- 按 Enter 键触发"下一步"

**操作**：
1. 在答案输入框中输入密保答案（不区分大小写）
2. 点击"下一步"按钮或按 Enter

**后端请求**：`POST /api/auth/forgot-password`，发送 `{ step: 'verify_answer', username, answer }`

**成功**：
- 获取 `resetToken`（用于下一步重置密码）
- 自动进入第三步

**失败**：
- 显示红色错误提示框（如"答案错误，请重试"）

### 第三步：设置新密码

**界面内容**：
- 标题："**第三步：设置新密码**"
- 说明文字："为账号「**xxx**」设置新密码"（账号名加粗显示）
- **新密码输入框**（自动聚焦）：
  - placeholder `至少 6 个字符`
  - 右侧有眼睛图标按钮，可切换密码显示/隐藏
- **确认新密码输入框**：
  - placeholder `再次输入新密码`
  - 跟随新密码的显示/隐藏状态
- 按 Enter 键可触发"重置密码"

**操作**：
1. 输入新密码（至少 6 位）
2. 再次输入新密码确认
3. 点击"重置密码"按钮

**前端校验**：
- 新密码至少 6 个字符
- 两次输入的密码必须一致

**后端请求**：`POST /api/auth/forgot-password`，发送 `{ step: 'reset_password', resetToken, newPassword }`

**成功**：
- 进入完成页面

**失败**：
- 显示红色错误提示框
- **特殊情况——token 过期**：如果返回 401 状态码，自动回到第一步（用户名步骤），清空答案和 resetToken，需要重新验证身份

### 完成页面

密码重置成功后显示：

- 居中布局，白色卡片内
- **绿色圆形大✓图标**（直径 64px，翠绿背景 + 白色勾）
- "**密码重置成功**" 标题

### 导航按钮

每步底部有两个按钮，左右并排：

| 步骤 | 左按钮 | 右按钮 |
|------|--------|--------|
| 第一步 | "返回登录"（灰色）→ 跳转 `/login` | "下一步"（蓝绿渐变） |
| 第二步 | "上一步"（灰色）→ 回到第一步 | "下一步"（蓝绿渐变） |
| 第三步 | "上一步"（灰色）→ 回到第二步 | "重置密码"（蓝绿渐变） |

- 加载中时右按钮变为禁用状态，显示"处理中..."
- 左按钮 hover 时背景变深（`bg-slate-200`）
- 右按钮始终为蓝绿渐变（翠绿 → 天蓝），有轻微阴影

## 特殊情况

### 情况一：网络错误

所有 API 请求如果因网络原因失败（如断网、服务端不可达），在对应位置显示红色错误提示"网络错误"。刷新页面或重试操作可恢复。

### 情况二：登录态过期

如果用户长时间未操作导致登录态过期，访问需要登录的页面时会自动跳转到登录页。登录后会回到之前访问的页面。

### 情况三：注册时用户名查重接口失败

如果查重接口响应异常（如网络波动），用户名状态自动重置为 `idle`（不显示任何提示），用户仍可继续注册，注册时由后端做最终校验。

### 情况四：忘记密码 token 过期

在第三步重置密码时，如果 `resetToken` 已过期（服务端返回 401），系统自动回到第一步重新验证账号。用户需要重新输入用户名和密保答案。
