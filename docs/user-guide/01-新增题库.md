# 新增题库

## 功能说明

新增题库是指用户将自己准备的题目导入系统，系统自动解析为结构化题目，创建为个人题库。创建后即可开始答题。

支持两种内容输入方式：
- **上传文件**：从本地选择 .md / .txt / .pdf / .docx / 图片文件
- **粘贴文本**：直接在文本框中粘贴 Markdown 格式的题目

解析方式分为两种：
- **本地解析**：系统内置规则解析，即时完成，不消耗积分
- **AI 解析**：调用 AI 大模型智能解析，约 10~30 秒，适合复杂格式或图片 OCR

---

## 进入上传页面

有两种方式进入上传页面：

### 方式一：从首页进入

1. 登录系统后，进入首页（题库列表页）。
2. 页面左侧有一个**侧边栏**（如果侧边栏收起，将鼠标移到屏幕最左侧，会出现一个把手，点击把手即可展开侧边栏）。
3. 在侧边栏中找到导航项 **"上传新题库"**（图标为 ↑ 箭头），点击它。
4. 页面跳转至 `/upload`，即上传题库页面。

### 方式二：直接访问

在浏览器地址栏中直接输入 `/upload` 路径，或从"题库管理"页面点击相关入口。未登录用户会自动跳转到登录页，登录后回到上传页面。

## 步骤一：准备题目内容

### A. 上传文件

**操作步骤：**

1. 找到页面上的**文件拖拽区**——这是一个带虚线边框的大矩形区域，中间有一个蓝色到绿色渐变的圆形图标（内含上传箭头），下方有文字"拖拽文件到此处，或点击下方按钮选择"，文字下方有一个**"选择文件"**按钮（蓝绿渐变圆角按钮）。

2. 通过以下任一方式选择文件：
   - **拖拽**：打开系统文件管理器（如 Windows 资源管理器），找到要上传的文件，用鼠标按住文件拖到页面上的虚线区域内，松开鼠标。
   - **点击按钮**：点击"选择文件"按钮，系统弹出文件选择对话框，浏览本地文件并选中一个文件，点击"打开"。

3. 系统会检查文件：

   **文件大小检查：**
   - 如果文件超过 **10MB**，页面会在文本编辑区上方显示红色错误提示框："文件超过 10MB 限制"。此时需要换一个更小的文件。
   - 错误提示框左侧有 ⚠ 图标，右侧显示红色文字。

   **文件类型与处理方式：**

   | 文件后缀 | 处理方式 | 页面表现 |
   |----------|----------|----------|
   | `.md` `.txt` | 浏览器直接读取文件文本内容 | 无加载过程，文本立即显示在编辑区 |
   | `.pdf` | 上传到服务端提取文字 | "选择文件"按钮变为不可点击状态，短暂等待后文本显示在编辑区 |
   | `.docx` | 上传到服务端提取文字 | 同上 |
   | `.png` `.jpg` `.jpeg` `.webp` | 上传到服务端，调用 AI 视觉模型 OCR 识别 | 同上，**需要管理员已配置支持视觉的 AI 厂商** |
   | `.doc` | **不支持** | 显示错误："`.doc` 格式不支持,请另存为 `.docx`" |
   | 其他后缀 | **不支持** | 显示错误："不支持的文件类型: .xxx" |

4. 文件内容提取成功后，文本自动填入下方的**文本编辑区**。此时可以手动修改编辑区中的文本内容（如修正 OCR 识别错误、调整格式等）。

### B. 直接粘贴文本

**操作步骤：**

1. 找到**文本编辑区**——这是一个大的多行文本框，高度约 256px，浅色背景带圆角边框。框内有一个浅灰色占位提示文字："在此粘贴 Markdown 格式的题目..."。

2. 将准备好的 Markdown 格式题目文本粘贴到文本框中。可以从任何地方复制（如已有的 .md 文件、网页内容等）。

3. 粘贴后可以继续手动编辑、修改文本内容。

### Markdown 格式要求

系统通过识别 Markdown 标题层级和关键词来区分题型和答案。必须遵循以下格式：

**整体结构：**

```
# 题库标题          ← 一级标题作为题库名称（可选，不写则自动取首行前50字）

## 一、单选题       ← 二级标题含"选择"或"单选"关键词 → 识别为单选题区
## 二、填空题       ← 二级标题含"填空"关键词 → 识别为填空题区
## 三、简答题       ← 二级标题含"简答"关键词 → 识别为简答题区
## 四、面试题       ← 二级标题含"面试"关键词 → 识别为面试题区
## 五、答案         ← 二级标题含"答案"关键词 → 识别为答案区
```

**单选题格式：**

```
## 一、单选题

1. 以下哪个是 JavaScript 的基本数据类型？
A. Array
B. String
C. Object
D. Date

2. HTTP 状态码 404 表示什么？
A. 服务器错误
B. 资源未找到
C. 未授权
D. 请求超时
```

- 每题以数字编号 `1.` `2.` 开头，后跟题目文字
- 选项以 `A.` `B.` `C.` `D.` 开头（支持 `.` `、` `)` 三种分隔符）
- 系统自动提取 4 个选项
- 题目中 `（xxx）` 括号内容会被自动去除

**填空题格式：**

```
## 二、填空题

1. HTTP 协议默认端口号是____。
2. 在 Python 中，使用____关键字定义函数。
```

- 题目中的 `____` 或 `（xxx）` 会被识别为填空位置
- 系统自动统计每题的填空数量

**简答题格式：**

```
## 三、简答题

1. 请简述 RESTful API 的设计原则。
2. 什么是闭包？请举例说明。
```

- 每题以数字编号开头，后跟问题描述
- 没有选项，由用户自由输入答案

**面试题格式：**

```
## 四、面试题

1. 请介绍一下你在项目中遇到的最大技术挑战。
   - 你具体负责了哪些部分？
   - 最终是如何解决的？
2. 谈谈你对微服务架构的理解。
```

- 每题以数字编号开头
- 子问题以 `- ` 或 `• ` 开头，缩进在主问题下方
- 子问题会在答题界面中展示在主问题下方

**答案区格式：**

```
## 五、答案

### 选择题答案
1. B
2. B

### 填空题答案
1. 80
2. def

### 简答题答案
1. RESTful API 设计原则包括：资源导向、统一接口、无状态等。
2. 闭包是指函数能访问其外部作用域变量。

### 面试题答案
1. 参考答案内容...
```

- 答案区标题必须含"答案"关键词（系统会查找第一个含"答案"的二级标题段）
- 按小题序号 `1.` `2.` 列出对应答案
- 选择题答案写选项字母即可（如 `B` 或 `A,C`）
- 填空题多个答案用逗号或分号分隔
- 简答题和面试题的答案会作为**参考答案**展示

## 步骤二：设置答题时长（可选，可跳过）

1. 找到**答题时长设置区**——位于文件拖拽区和文本编辑区之间，是一个白色圆角矩形卡片。

2. 卡片内从上到下依次为：
   - 标签文字："答题时长(可选)"
   - **输入框**：白色小输入框，宽约 96px，内有浅色占位文字 "0"
   - 输入框右侧灰色文字："分钟"
   - 提示文字："0 = 不限时，1~480 分钟可选"
   - **快捷按钮行**：四个小按钮，分别标有 `10 分钟`、`20 分钟`、`30 分钟`、`60 分钟`

3. 设置方式（任选其一）：
   - **手动输入**：在输入框中直接输入数字（范围 0~480），输入非数字会自动转为 0
   - **快捷选择**：点击下方四个快捷按钮中的任意一个，输入框会自动填入对应数字。被选中的按钮会高亮显示（蓝色背景 + 蓝色边框）

4. 规则说明：
   - 设为 **0 或不填** → 答题时**不限时**
   - 设为 1~480 → 答题时有倒计时，**时间到自动提交**，中途剩余 5 分钟和 1 分钟时会有弹窗提醒

## 步骤三：开始解析

### 前提条件

- 文本编辑区必须**有内容**（不为空），否则"开始解析"按钮为灰色禁用状态，无法点击。
- 如果内容是通过上传文件自动填入的，可以手动修改后再解析。

### 操作步骤

1. 确认文本编辑区的内容无误后，点击下方的**"开始解析"**按钮（蓝绿渐变圆角按钮，位于"清空"按钮右侧）。

2. 点击后系统会判断 AI 厂商的可用性：

   **情况 A：AI 厂商已配置且激活 → 弹出"选择解析方式"对话框**

   对话框弹出后，页面背景变暗（半透明黑色遮罩）。对话框内容：

   - 顶部标题："**选择解析方式**"
   - 标题下方灰色小字："选完后会自动开始解析并进入答题"
   - 中间两个大卡片并排：

     **左侧卡片——本地解析 ⚡：**
     - 卡片有浅蓝绿渐变背景，蓝色边框
     - 标题：闪电图标 + "**本地解析**"
     - 副标题：灰色小字"即时完成"
     - 特点列表（灰色小字）：
       - `• 适合格式规范的 Markdown`
       - `• 无需网络,无 API 成本`
       - `• 代码题支持较弱`

     **右侧卡片——AI 解析 🧠：**
     - 卡片有浅紫粉渐变背景，紫色边框
     - 标题：大脑图标 + "**AI 解析**"
     - 副标题：灰色小字"预计 10-30 秒"
     - 特点列表（灰色小字）：
       - `• 适合代码题 / 复杂格式`
       - `• 需调用 AI 厂商 API`
       - `• 图片 OCR 必需`

   - 卡片下方有一个灰色小字链接："**稍后再说**"

   在此对话框中：
   - 点击**"本地解析"卡片** → 选择本地解析，对话框关闭，进入解析进度阶段
   - 点击**"AI 解析"卡片** → 选择 AI 解析，对话框关闭，进入解析进度阶段
   - 点击**"稍后再说"** → 关闭对话框，回到编辑页面，不进行解析
   - 按键盘 **`Esc` 键** → 同上，关闭对话框
   - 点击对话框外部的**暗色遮罩区域** → 同上，关闭对话框

   **情况 B：AI 厂商未配置或未激活 → 跳过对话框，直接使用本地解析**

   点击"开始解析"后不会弹出选择对话框，直接进入本地解析进度阶段。

---

## 步骤四：等待解析完成

点击解析方式后，页面弹出**解析进度对话框**，背景变暗。

### 本地解析

对话框显示：
- 顶部标题：⚡ "**本地解析中**"，右侧显示百分比数字（如 `100%`）
- 下方一条细长的进度条（灰色底，蓝绿渐变填充条），从 5% 快速跳到 100%
- 进度条下方灰色小字显示当前状态（如"解析完成，共 10 题"）
- 底部有一个灰色"**取消**"按钮

本地解析通常在瞬间完成（小于 1 秒）。解析完成后，对话框自动关闭，进入保存和跳转阶段。

### AI 解析

对话框显示：

- 顶部标题：🧠 "**AI 解析中**"，右侧显示实时百分比数字
- 进度条（灰色底，蓝绿渐变填充条），实时增长
- 进度条下方灰色小字显示实时状态信息
- 一个**黑色代码块区域**——展示 AI 实时流式输出的原始文本（绿色等宽字体，黑底），内容逐字出现，可上下滚动
- 底部有一个灰色"**取消**"按钮

**AI 解析各阶段：**

| 阶段 | 进度 | 状态文字 |
|------|------|----------|
| 准备 | 5%~8% | "正在准备..." → "AI 正在解析题目..." |
| 流式生成 | 8%~88% | "AI 正在解析...（xxx 字符）" |
| JSON 解析 | 88%~93% | "AI 已响应（xxx 字符），正在解析..." |
| 规范化 | 93%~100% | "规范化题目..." |
| 完成 | 100% | "解析完成" |

- 流式生成阶段：黑色代码框中的绿色文字会实时增长
- 进度百分比是估算值，实际速度取决于 AI 厂商响应速度
- 预计总耗时 10~30 秒

**中断解析：**

- 随时可点击**"取消"**按钮中断解析，对话框关闭，回到编辑页面
- 已解析的内容不会被保存

**解析失败：**

如果 AI 调用出错，对话框变为错误状态：
- 进度条消失
- 出现红色/粉红色错误提示框
- 框内显示错误信息文字
- 框内有一个"**关闭**"按钮

点击"关闭"回到编辑页面，可以检查文本格式或重试。

**文本截断：**

如果文本超过 **60,000 字符**，解析过程中会显示提示"文本超过 60000 字符，已截断"，超出部分不会被解析。

---

## 步骤五：保存题库并进入答题

解析完成后，系统自动执行以下操作：

1. 提取题库名称：取文本中一级标题（`# xxx`）作为题库名称；若无一级标题，取文本首行前 50 个字符。
2. 计算文件指纹：对文本内容计算 SHA-256 哈希值，用于识别重复上传。
3. 调用后台接口创建题库，保存所有解析出的题目。
4. 页面自动跳转到 `/quiz/[题库ID]`（答题页面）。

跳转后即可开始答题。

## 特殊情况

### 情况一：重复上传同一文件

**触发条件**：上传的文件内容 SHA-256 指纹与之前上传过的某个文件**完全相同**。

解析完成后，不会直接跳转，而是弹出**"检测到已存在的题库"**提示对话框。

对话框内容：
- 标题："**检测到已存在的题库**"
- 说明文字：根据实际情况显示不同提示
- 操作按钮：根据实际情况显示不同选项

**场景与对应操作：**

| 场景 | 提示文字 | 按钮选项 |
|------|----------|----------|
| 有**未提交的答题进度**（草稿） | "这份文件之前有未提交的进度。" | ① **"继续上次进度"**（蓝绿渐变按钮）——恢复到上次暂存的答题状态，答题卡中之前的答案还在；② **"重新开始(清空旧进度)"**（灰色按钮）——删除旧草稿，从零开始答题 |
| 已有**完成的答题记录**，无草稿 | "这份文件已经有完成记录。" | ① **"查看已有完成记录"**（蓝绿渐变按钮）——跳转到首页，定位到该题库 |
| 仅有题库有记录但无答题 | "这份文件已经有完成记录。" | ① **"进入答题"**（蓝绿渐变按钮）——直接跳转到答题页面 |

所有场景下还有一个**"取消"**按钮，点击后关闭对话框，回到上传页面。

### 情况二：清空内容

点击**"清空"**按钮（白色按钮，位于"开始解析"左侧），文本编辑区内容被清空，错误提示（如有）也一并清除。

当文本编辑区为空时，"清空"按钮和"开始解析"按钮都处于**禁用状态**（灰色、透明度降低、鼠标变为禁止图标）。

### 情况三：页面状态说明

- **加载中**：上传 PDF/DOCX/图片时，文本提取过程中按钮显示为不可点击状态
- **错误状态**：错误信息显示为红色/粉红背景的提示条，位于文本编辑区上方

## 快速参考：题目 Markdown 模板

以下是一个可直接复制使用的完整模板：

```markdown
# 前端基础知识测试

## 一、单选题

1. 以下哪个不是 JavaScript 的基本数据类型？
A. Number
B. String
C. Array
D. Boolean

2. CSS 中 `position: fixed` 是相对于什么定位？
A. 父元素
B. 浏览器窗口
C. 文档流
D. 最近的定位祖先

## 二、填空题

1. HTML 中，超链接的 href 属性值为____时，会打开系统默认邮件客户端。
2. 在 Flexbox 布局中，`justify-content` 属性用于控制____方向的对齐方式。

## 三、简答题

1. 请解释什么是事件冒泡和事件捕获。

2. 简述 Cookie、LocalStorage 和 SessionStorage 的区别。

## 四、面试题

1. 请描述一下你从输入 URL 到页面渲染完成的整个过程。
   - DNS 解析过程是怎样的？
   - TCP 三次握手做了什么？

## 五、答案

### 选择题答案
1. C
2. B

### 填空题答案
1. mailto:
2. 主轴

### 简答题答案
1. 事件冒泡是指事件从最内层的目标元素向外层元素逐级触发；事件捕获则相反，从最外层向内层逐级触发。

2. Cookie 存储量小(4KB)，每次 HTTP 请求自动发送到服务器；LocalStorage 存储量大(5MB)，数据持久保存；SessionStorage 存储量大(5MB)，但关闭标签页后数据清除。
```
