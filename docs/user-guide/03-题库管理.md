# 题库管理

## 功能说明

题库管理是对用户已创建的个人题库进行统一管理的页面。在这里可以浏览、搜索、排序、筛选、重命名、修改分类、删除题库，以及导出题库为 Markdown 文件或 ZIP 压缩包。

注意：题库管理页面**仅显示用户自己创建的题库**，不包含官方题库。

---

## 进入题库管理页面

有两种方式进入题库管理页面：

### 方式一：从侧边栏进入

1. 登录系统后，进入首页（题库列表页）。
2. 页面左侧有一个**侧边栏**（如果侧边栏收起，将鼠标移到屏幕最左侧，会出现一个把手，点击把手即可展开侧边栏）。
3. 在侧边栏中找到导航项 **"题库管理"**，点击它。
4. 页面跳转至 `/banks`，即题库管理页面。

### 方式二：直接访问

在浏览器地址栏中直接输入 `/banks` 路径。未登录用户会自动跳转到登录页，登录后回到题库管理页面。

---

## 页面布局

进入题库管理页面后，页面从上到下依次显示：

| 区域 | 位置 | 说明 |
|------|------|------|
| 顶部导航栏 | 页面最上方 | 左侧"返回首页"按钮，中间标题"题库管理"（标题上方有小字"MY LIBRARY"），右侧空白占位 |
| 工具条 | 导航栏下方 | 单行：搜索框 + 排序下拉 + 分类筛选下拉 + "管理"按钮 |
| 批量操作条 | 工具条下方 | 仅管理模式显示：浅蓝色背景，显示已选数量和批量操作按钮 |
| 题库列表 | 批量操作条下方 | 逐条显示题库卡片 |
| Toast 通知 | 页面右上角 | 操作成功/失败的短暂提示 |

## 浏览题库列表

### 列表卡片

每条题库以一张白色圆角卡片展示，内容分为左右两部分：

**左侧主体信息：**
- **标题**（加粗，14px，深灰色）：点击标题可进入该题库的答题页面。鼠标悬停时标题变为蓝色。
- **副行信息**（小字，浅灰色），从左到右依次为：
  - 创建时间，格式 `YYYY-MM-DD HH:mm`
  - 答题时长（如有设置），如"60 分钟"
  - 分类标签（圆角小标签，灰底灰字，含分类图标和名称），未分类则显示灰色文字"未分类"
  - 最近答题时间（如有答题记录），格式同创建时间

**右侧操作按钮：**
- 默认状态下操作按钮透明度较低，鼠标悬停在卡片上时完全显示
- 按钮依次为：**答题**、**导出**、**分类下拉框**、**重命名**、**删除**

### 加载状态

页面初次加载时，列表区域显示 3 个灰白色占位卡片，带有脉搏动画效果。数据加载完成后显示实际列表。

## 搜索题库

1. 在工具条左侧找到**搜索框**。搜索框左侧有一个放大镜图标，内部有浅灰色占位文字"搜索题库标题…"。

2. 在搜索框中输入关键词，列表会**实时过滤**，只显示标题中包含该关键词的题库（不区分大小写）。

3. 清空搜索框即可恢复显示全部题库。

4. 搜索结果为空时，列表区域显示："没找到匹配「xxx」的题库"（灰色文字）。

---

## 排序

1. 在搜索框右侧找到**排序下拉框**。

2. 点击下拉框，可选择以下排序方式：

   | 选项 | 排序规则 |
   |------|----------|
   | 按创建时间 | 按创建时间从新到旧排列（默认） |
   | 按标题 | 按标题拼音字母顺序排列（支持中文） |

3. 选择后列表立即重新排列。

---

## 分类筛选

1. 在排序下拉框右侧找到**分类筛选下拉框**。

2. 点击下拉框，可选择以下筛选条件：

   | 选项 | 说明 |
   |------|------|
   | 全部分类 | 显示所有题库，不进行筛选 |
   | 🐬 MySQL | 筛选分类为 MySQL 的题库 |
   | 🟥 Redis | 筛选分类为 Redis 的题库 |
   | 🐧 Linux | 筛选分类为 Linux 的题库 |
   | 🌐 计算机网络 | 筛选分类为"计算机网络"的题库 |
   | ⚙️ 操作系统 | 筛选分类为"操作系统"的题库 |
   | 🧮 算法与数据结构 | 筛选分类为"算法与数据结构"的题库 |
   | 🎨 前端 | 筛选分类为"前端"的题库 |
   | 🛠️ 后端 | 筛选分类为"后端"的题库 |
   | 📚 其他 | 筛选分类为"其他"的题库 |
   | 📂 未分类 | 筛选未设置分类的题库 |
   | 🏷️ 自定义分类 | 用户自己创建的分类（如有），排在预设分类之后 |

3. 选择后列表立即过滤显示。

## 重命名题库

### 操作步骤

1. 将鼠标悬停在目标题库卡片上，右侧出现操作按钮。

2. 点击**"重命名"**按钮。

3. 题库标题位置变为一个**白色输入框**，框内有蓝色聚焦边框，内容为当前标题文字。输入框自动聚焦并全选，方便直接修改。

4. 输入框右侧出现两个小按钮：
   - **"保存"**（蓝色圆角按钮）
   - **"取消"**（灰色文字按钮）

5. 输入新的标题名称后，点击**"保存"**按钮。

6. 系统调用 `PATCH /api/quizzes/[id]` 接口更新标题。

7. 保存成功后：
   - 输入框恢复为普通标题文字，显示新标题
   - 右上角弹出绿色 Toast 提示"已重命名（点击关闭）"

### 取消重命名

以下任一操作均可取消重命名，恢复原标题：

- 点击**"取消"**按钮
- 按键盘 **`Esc` 键**
- 点击输入框外部区域（**blur**）

### 输入校验

- 如果输入的新标题为**空**（全是空格），点击保存后会弹出红色 Toast 提示"标题不能为空"，不会提交到后端。
- 如果新标题与原标题**完全相同**，直接退出重命名状态，不发起请求。

## 修改分类

修改分类不需要进入管理模式，直接在每条题库行内操作即可。

### 操作步骤

1. 在目标题库卡片的右侧操作按钮中找到**分类下拉框**（一个小型下拉选择框，默认显示当前分类名称）。

2. 点击下拉框，可看到以下选项：

   - **未分类**（默认值，排在第一位）
   - **预设分类**：🐬 MySQL、🟥 Redis、🐧 Linux、🌐 计算机网络、⚙️ 操作系统、🧮 算法与数据结构、🎨 前端、🛠️ 后端、📚 其他
   - **自定义分类**（如有）：以"🏷️ 我的分类"分组标题开头，下方列出用户自己创建的分类

3. 直接点击要切换到的目标分类。

4. 系统调用 `PATCH /api/quizzes/[id]` 接口更新分类。

5. 成功后：
   - 分类下拉框显示新选中的分类
   - 副行分类标签同步更新
   - 右上角弹出绿色 Toast 提示"已更新分类（点击关闭）"

---

## 删除单个题库

### 操作步骤

1. 将鼠标悬停在目标题库卡片上，右侧出现操作按钮。

2. 点击**"删除"**按钮。

3. 页面弹出**确认对话框**，背景变暗（半透明黑色遮罩 + 模糊效果）。对话框内容：
   - 标题："**删除题库**"
   - 内容文字："确定要删除题库「xxx」吗？该题库下的所有答题记录也会被一起删除。"
   - 左侧按钮：**"取消"**（灰色背景按钮）
   - 右侧按钮：**"删除"**（红色背景按钮，危险样式）

4. 在对话框中：
   - 点击**"删除"**按钮 → 确认删除，调用 `DELETE /api/quizzes/[id]` 接口
   - 点击**"取消"**按钮 → 取消操作，关闭对话框
   - 点击对话框外部的**暗色遮罩区域** → 同上，取消操作
   - 按键盘 **`Esc` 键** → 同上，取消操作

5. 确认删除后：
   - 该题库从列表中移除
   - 右上角弹出绿色 Toast 提示"已删除（点击关闭）"

## 管理模式（批量操作）

管理模式允许同时选中多个题库，进行批量导出或批量删除。

### 进入管理模式

点击工具条最右侧的**"管理"**按钮（灰色边框，大写字母 "GUAN LI" 样式）。点击后：

- "管理"按钮变为**蓝色"取消"按钮**（蓝色背景白色文字）
- 列表中每条题库卡片左侧出现一个**蓝色圆形复选框**
- 列表上方出现**批量操作条**（浅蓝色背景，圆角边框）

### 选中/取消选中题库

- 点击某条题库左侧的**复选框**：选中时复选框变为蓝色实心并显示白色 ✓ 勾号；再次点击取消选中
- 批量操作条左侧实时显示 **"已选 X / Y 项"**（蓝色高亮数字）

### 全选/取消全选

- 点击批量操作条中的**"全选"**按钮 → 选中当前筛选视图中的所有题库
- 当所有项已选中时，按钮文字变为**"取消全选"**，点击后清空所有选中

### 退出管理模式

- 点击工具条右侧的**蓝色"取消"按钮** → 退出管理模式，所有选中状态被清空，复选框和批量操作条消失

---

## 批量删除

### 操作步骤

1. 进入**管理模式**。

2. 勾选需要删除的题库（可通过全选快速选中）。

3. 点击批量操作条中的**"删除"**按钮（红色背景白色文字）。如果没有选中任何题库，该按钮为灰色禁用状态。

4. 页面弹出**确认对话框**。对话框内容：
   - 标题："**批量删除题库**"
   - 内容文字："确定要删除选中的 N 个题库吗？它们下面的所有答题记录也会被一起删除。"
   - 左侧按钮：**"取消"**（灰色背景按钮）
   - 右侧按钮：**"删除"**（红色背景按钮，危险样式）

5. 点击**"删除"**按钮确认。系统逐个调用 `DELETE /api/quizzes/[id]` 接口。

6. 删除过程中"删除"按钮变为**"删除中…"**并禁用，防止重复点击。

7. 删除完成后：
   - 所有被选中的题库从列表中移除
   - 右上角弹出绿色 Toast 提示"已删除 N 个题库（点击关闭）"
   - 自动退出管理模式

## 导出功能

导出功能可生成题库的 Markdown 文件，支持单个导出和批量导出，批量导出时自动打包为 ZIP 压缩包。

### 导出单个题库

1. 在目标题库卡片的右侧操作按钮中，点击**"导出"**按钮。

### 批量导出

1. 进入**管理模式**。
2. 勾选需要导出的题库。
3. 点击批量操作条中的**"导出"**按钮（绿色背景白色文字）。如果没有选中任何题库，该按钮为灰色禁用状态。

### 导出选项对话框

点击导出按钮后，页面弹出**"导出选项"**对话框，背景变暗。对话框内容：

- 标题："**导出选项**"
- 说明文字："即将导出 N 个题库。选择需要包含的附加内容："

- 选项列表（复选框）：
  - **题目与答案** — 默认勾选，灰色不可取消，右侧有灰色小字说明"（默认包含）"
  - **AI 解析** — 默认不勾选，可点击切换
  - **追问记录** — 默认不勾选，可点击切换
  - **答题报告** — 默认不勾选，可点击切换
  - **全选** — 点击可一键勾选/取消上面三项附加内容

- 底部按钮：
  - **"取消"**（灰色背景按钮）— 关闭对话框，不导出
  - **"确认导出"**（蓝绿渐变按钮）— 开始导出

### 导出结果

导出过程中"确认导出"按钮变为**"导出中…"**并禁用。

**单个题库导出：**
- 生成一个 `.md` 文件，文件名格式为 `题库标题.md`（非法文件名字符会被替换为下划线）
- 文件内容为 Markdown 格式，包含题库标题、题目、答案，以及选中的附加内容（AI 解析、追问记录、答题报告）
- 浏览器自动下载该文件
- 右上角弹出绿色 Toast 提示"已导出「题库标题」（点击关闭）"

**批量导出：**
- 生成一个 `.zip` 压缩包，文件名格式为 `题库导出_YYYY-MM-DD_N套.zip`
- ZIP 包内每个题库对应一个 `.md` 文件
- 浏览器自动下载该压缩包
- 右上角弹出绿色 Toast 提示"已导出 N 个题库（点击关闭）"

### 对话框关闭方式

- 点击**"取消"**按钮
- 点击对话框外部的**暗色遮罩区域**
- 按键盘 **`Esc` 键**

## 空状态

### 情况一：没有任何自己的题库

当用户尚未创建任何题库时，列表区域显示：

- 灰色虚线边框的空白区域
- 中间显示灰色文字"**还没有自己的题库**"
- 下方有一个蓝色**"前往首页上传"**按钮

点击"前往首页上传"按钮跳转到首页，在首页可找到上传入口。

### 情况二：搜索无结果

当搜索关键词没有匹配到任何题库时，列表区域显示：

- 灰色文字"**没找到匹配「xxx」的题库**"

修改或清空搜索关键词即可恢复显示。

## Toast 通知

所有操作完成后，页面右上角会弹出 Toast 通知条。Toast 的特点：

| 属性 | 说明 |
|------|------|
| **位置** | 页面右上角固定定位，不随页面滚动而移动 |
| **样式** | 成功为绿色背景（浅绿底 + 绿色边框 + 深绿文字）；失败为红色背景（浅红底 + 红色边框 + 红色文字） |
| **文字** | 操作结果描述 + 灰色小字"（点击关闭）" |
| **持续时间** | 约 2.4 秒后自动消失 |
| **手动关闭** | 点击 Toast 任意位置可立即关闭 |
| **层级** | 位于所有元素之上（z-index 最高） |
