# 笔记

## 功能说明

笔记功能允许你在答题过程中随时记录想法、保存 AI 解析结果、或收藏参考答案。每条笔记使用 Markdown 格式，可关联到具体的题目、测验或答题结果。

笔记按类型分为三种：
- **题目笔记（question）**：针对某道题目本身的笔记，如解题思路、知识点总结
- **答题笔记（answer）**：针对某次答题的笔记，如错题分析、答题心得
- **AI 输出（ai_output）**：保存 AI 解析或 AI 报告的内容

笔记按来源分为四种：
- **手动记录（manual）**：用户自行创建的笔记
- **AI 解析（ai_explain）**：从 AI 单题解析中保存的内容
- **标准答案（reference_answer）**：从参考答案中保存的内容
- **AI 报告（ai_report）**：从答题报告中保存的内容

笔记通过两种途径访问：
- **答题页面中的 NotePanel 侧面板**：在答题时记录与当前题目相关的笔记
- **独立的笔记管理页面（/notes）**：集中查看、搜索、编辑所有笔记

---

## 在答题页面记笔记

### 进入方式

在答题页面（答案速查视图），每道题的展开区域中都有一个"笔记"按钮。

**位置说明：**

1. 进入答题页面后，在左侧答题卡区域逐题展开。
2. 每道题的展开区域中，"你的答案"标签右侧有一个**紫色边框的小按钮**，上面写着"笔记"。
3. 面试题类型会在"AI 评分"标题行右侧同样显示该按钮。
4. 点击该按钮，页面右侧会滑出 NotePanel 侧面板。

### NotePanel 侧面板

NotePanel 是一个从右侧滑入的抽屉面板，宽度约 384px，覆盖在答题页面上方。面板分为三个区域：

| 区域 | 位置 | 说明 |
|------|------|------|
| 头部栏 | 面板最上方 | 左侧标题"笔记"（带笔图标），右侧关闭按钮（X） |
| 编辑区 | 头部栏下方 | 笔记类型选择 + 标题输入框 + 内容编辑区 + 保存/取消按钮 |
| 笔记列表 | 编辑区下方，占满剩余高度 | 显示与该题/该测验关联的所有笔记，可滚动 |

## 步骤一：新建笔记

### A. 手动创建笔记

1. 在答题页面展开某道题目，点击"笔记"按钮，NotePanel 从右侧滑入。
2. 面板打开后，编辑区默认处于新建模式。如果当前处于查看或编辑其他笔记的状态，直接在下方的编辑区输入即可（编辑区始终可见）。

3. **选择笔记类型：**
   - 编辑区第一行是一个下拉选择框，默认选中"答题笔记"
   - 点击下拉框可切换为"题目笔记"或"AI 输出"
   - 选择合适的类型

4. **输入标题：**
   - 在"笔记标题"输入框中输入标题，最长 **200 字**
   - 标题为必填项

5. **输入内容：**
   - 在"笔记内容（支持 Markdown）"文本框中输入内容
   - 文本框高度为 5 行，可输入多行文本
   - 内容支持 Markdown 语法（如标题、列表、代码块、加粗等）
   - 内容为必填项

6. **保存笔记：**
   - 点击下方蓝紫色（indigo-600）"保存"按钮
   - 保存时按钮显示"保存中..."，完成后按钮恢复
   - 笔记将自动关联到当前题目（questionId）、当前测验（quizId）和当前答题结果（resultId）
   - 保存成功后，笔记出现在下方的笔记列表中，编辑区表单清空

7. 如果标题或内容为空，"保存"按钮为灰色禁用状态，无法点击。

### B. 从 AI 解析记笔记

当你在答题页面使用 AI 单题解析功能后，可以快速将 AI 解析结果保存为笔记。

1. 在某道题下方展开 AI 解析结果。
2. AI 解析内容旁有"记笔记"入口（具体位置取决于功能实现）。
3. 点击后，NotePanel 面板打开，内容编辑区**自动填入 AI 解析的完整内容**。
4. 笔记类型自动设为"AI 输出"，来源自动标记为"AI 解析"（ai_explain）。
5. 输入标题后，直接点击"保存"即可。

同理，从参考答案处点击"记笔记"时，内容自动填入参考答案文本，来源标记为"标准答案"（reference_answer）。

## 步骤二：查看与编辑已有笔记

### 查看笔记列表

1. NotePanel 打开后，下方的笔记列表自动加载与该题和该测验相关的所有笔记。
2. 加载时显示"加载中..."文字。
3. 若没有笔记，显示"暂无笔记"。
4. 每条笔记以灰色圆角卡片（bg-slate-50）展示，包含以下信息：
   - **类型标签**：紫色小标签（indigo-600 文字 + indigo-50 背景），显示"题目笔记"/"答题笔记"/"AI 输出"
   - **来源标签**：灰色小字，显示来源（手动记录/AI 解析/标准答案/AI 报告）。来源为"手动记录"时不显示
   - **标题**：黑色加粗文字（slate-800），过长时截断（truncate）
   - **内容预览**：灰色小字（slate-500），最多显示前 100 个字符，最多 2 行（line-clamp-2）

### 编辑笔记

1. 点击笔记列表中的某条笔记卡片，该笔记内容载入编辑区。
2. 编辑区顶部出现橙色"编辑中"标签（amber-600 文字 + amber-50 背景）。
3. 标题输入框显示当前笔记标题，内容编辑区显示当前笔记内容，类型下拉框显示当前类型。
4. 修改标题和/或内容后，点击"更新"按钮保存修改。
5. 点击"取消"按钮放弃修改，回到新建模式（表单清空）。

### 删除笔记

1. 将鼠标移到笔记列表中的某条笔记卡片上。
2. 卡片右上角出现红色删除图标（垃圾桶，hover 时由透明变为可见）。
3. 点击删除图标，该笔记立即从列表中移除（无需确认）。
4. 注意：删除操作不可撤销。

---

## 步骤三：关闭面板

点击面板右上角的 X 按钮，面板从右侧滑出消失。面板关闭时，编辑区表单自动清空（包括 AI 预设内容），下次打开时重新加载。

## 笔记管理页面

### 进入方式

**方式一：从侧边栏进入**

1. 登录系统后，展开侧边栏（如侧边栏已收起，将鼠标移至屏幕最左侧唤起把手）。
2. 在侧边栏中找到导航项 **"我的笔记"**（图标为铅笔/编辑图标），点击它。
3. 页面跳转至 `/notes`。

**方式二：直接访问**

在浏览器地址栏中输入 `/notes` 路径。未登录用户会看到"请先登录"提示。

进入 `/notes` 页面后，布局如下：

| 区域 | 位置 | 说明 |
|------|------|------|
| 页面标题 | 页面左上 | 大标题"我的笔记"，下方灰色副标题说明 |
| 新建按钮 | 页面右上 | 蓝紫色"+ 新建笔记"按钮 |

| 笔记列表 | 左侧栏（宽 320px） | 可滚动的笔记卡片列表 |
| 详情/编辑区 | 右侧主区域 | 查看笔记详情或编辑笔记 |

## 步骤四：筛选笔记

### 按类型筛选

筛选标签栏包含四个标签，默认选中"全部"：

| 标签 | 对应类型 | 说明 |
|------|----------|------|
| 全部 | — | 显示所有类型的笔记 |
| 题目笔记 | question | 仅显示题目笔记 |
| 答题笔记 | answer | 仅显示答题笔记 |
| AI 输出 | ai_output | 仅显示 AI 输出笔记 |

- 选中的标签为白色背景 + 阴影（bg-white shadow-sm），文字为深色加粗（slate-900 font-medium）
- 未选中的标签为灰色文字（slate-500），hover 时变为深色（slate-700）
- 点击标签即可切换筛选

### 搜索笔记

筛选标签栏右侧有一个搜索输入框：
- 输入关键词后，笔记列表**实时过滤**
- 搜索范围包括笔记**标题**和**内容**
- 搜索是子字符串匹配（大小写敏感取决于浏览器默认行为）
- 搜索与类型筛选同时生效（即先按类型筛选，再按关键词过滤）
- 清空搜索框后恢复全部显示

## 步骤五：查看笔记详情

### 选择笔记

1. 在左侧笔记列表中点击某条笔记卡片。
2. 选中的卡片变为**紫色高亮**状态：蓝色边框（border-indigo-300）+ 浅紫背景（bg-indigo-50）。
3. 右侧详情区显示该笔记的完整内容。

### 详情展示

选中笔记后，右侧详情区（白色圆角卡片，圆角-xl）显示：

- **顶部标签行：**
  - 紫色类型标签（如"题目笔记"）
  - 灰色来源标签（如"AI 解析"）
  - 右侧两个操作按钮："编辑"（蓝色）和"删除"（红色）

- **笔记标题：** 大号加粗文字（text-xl font-bold）

- **笔记正文：** 通过 MarkdownView 渲染的 Markdown 内容（prose 排版样式），支持标题、列表、代码块、加粗、链接等完整 Markdown 语法

- **底部时间：** 灰色小字显示"更新于 YYYY/MM/DD HH:mm:ss"

### 删除笔记（管理页面）

1. 在详情区右上角点击红色"删除"按钮。
2. 系统弹出浏览器确认对话框："确定要删除这条笔记吗？"
3. 点击"确定"后删除，列表刷新；点击"取消"放弃删除。
4. 如果删除的是当前选中的笔记，详情区回到空状态。

---

## 步骤六：新建与编辑笔记（管理页面）

### 新建笔记

1. 点击页面右上角的"+ 新建笔记"按钮。
2. 右侧详情区切换为编辑模式，显示白色圆角卡片。
3. 卡片顶部标题显示"新建笔记"。

4. **输入标题：**
   - 在"笔记标题"输入框中输入标题，最长 200 字
   - 标题为必填项

5. **输入内容：**
   - 在"笔记内容（支持 Markdown）"文本框中输入内容
   - 文本框高度为 12 行，可调整大小
   - 内容支持 Markdown 语法

6. **保存笔记：**
   - 点击蓝紫色"保存"按钮
   - 保存时如果标题或内容为空，按钮为灰色禁用状态
   - 保存成功后自动退出编辑模式，笔记出现在左侧列表中
   - 新建笔记的类型默认为"题目笔记"（question），来源默认为"手动记录"（manual），不关联具体题目或测验

7. 点击"取消"按钮退出编辑模式，回到之前的查看状态。

### 编辑已有笔记

1. 在左侧列表选中一条笔记（进入查看模式）。
2. 点击详情区右上角的蓝色"编辑"按钮。
3. 详情区切换为编辑模式，标题变为"编辑笔记"。
4. 标题输入框和内容编辑区预填当前笔记的内容。
5. 修改后点击"保存"，或点击"取消"放弃修改。

## 笔记类型与来源参考

### 类型标签对照

| 类型值 | 中文名称 | 使用场景 |
|--------|----------|----------|
| `question` | 题目笔记 | 记录解题思路、知识点、题目分析等 |
| `answer` | 答题笔记 | 记录错题分析、答题心得、反思总结 |
| `ai_output` | AI 输出 | 保存 AI 解析结果、AI 评分反馈、AI 报告内容 |

### 来源标签对照

| 来源值 | 中文名称 | 创建方式 |
|--------|----------|----------|
| `manual` | 手动记录 | 用户手动创建（NotePanel 或管理页面新建） |
| `ai_explain` | AI 解析 | 从 AI 单题解析功能保存 |
| `reference_answer` | 标准答案 | 从参考答案保存 |
| `ai_report` | AI 报告 | 从答题报告保存 |

### 笔记关联关系

每条笔记可以关联到以下实体（均为可选）：

| 关联字段 | 说明 |
|----------|------|
| questionId | 关联的题目 ID，表示该笔记属于某道题目 |
| quizId | 关联的测验 ID，表示该笔记属于某次测验 |
| resultId | 关联的答题结果 ID，表示该笔记属于某次答题记录 |

- 从答题页面 NotePanel 创建的笔记会自动关联当前题目（questionId）、当前测验（quizId）和当前答题结果（resultId）
- 从笔记管理页面新建的笔记不关联任何题目、测验或结果

## API 接口参考

笔记功能通过以下 API 端点实现，开发者可参考：

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/api/notes` | 获取当前用户笔记列表，支持 `type`、`questionId`、`quizId`、`resultId` 查询参数筛选 |
| `POST` | `/api/notes` | 创建笔记，必填字段：`type`（question/answer/ai_output）、`title`（最长 200 字）、`content`；选填：`questionId`、`quizId`、`resultId`、`source` |
| `GET` | `/api/notes/[id]` | 获取单条笔记详情 |
| `PUT` | `/api/notes/[id]` | 更新笔记，可更新 `title`、`content`、`type`、`source` 等字段 |
| `DELETE` | `/api/notes/[id]` | 删除笔记 |

所有接口需要登录认证（通过 Bearer token），笔记只能由创建者本人操作。
