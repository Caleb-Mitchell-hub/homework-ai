# 答题报告

## 功能说明

答题报告是系统根据用户答题结果自动生成的成绩分析页面。提交答卷后，用户可以在**答案速查**页面进入报告，查看得分总览、题型和难度维度的正确率分布，并可选择性地调用 AI 生成知识点分析和学习建议。

报告功能分为两大类：

- **普通题型报告**：适用于选择题、填空题、简答题等常见题型，提供统计图表和 AI 知识点分析（消耗 5 积分）
- **面试题深度分析**：当题库中全部为面试题或简答题时自动切换，提供综合评分、领域掌握情况等深度分析（消耗 100 积分）

---

## 进入报告页面

### 入口位置

报告页面的入口位于**答案速查**页面（即提交答卷后的结果查看页）。

1. 完成答题并点击"提交"后，页面自动跳转至答案速查页。
2. 在答案速查页的**顶部工具栏**中，找到 **"📊 查看报告"** 按钮。

   - 按钮样式为绿色边框、浅绿色背景、绿色文字
   - 位于工具栏右侧

3. 点击该按钮，页面跳转至 `/result/[结果ID]/report`，即**报告详情页**。

> **注意**：只有在提交答案、生成了答题结果后，"📊 查看报告"按钮才会出现。如果尚未提交，工具栏中没有此按钮。

---

## 报告页面加载

进入报告页面后，系统会执行以下加载流程：

1. 根据 URL 中的结果 ID，从服务端获取该次答题的结果数据。
2. 同时加载对应的题库信息（题目列表、题型、难度等）。
3. 系统在客户端自动计算统计指标（得分、正确率、题型分布、难度分布）。
4. 对于普通题型报告，系统会尝试加载之前已生成的 AI 报告缓存；如果是面试题，则不做缓存预加载。

**加载状态：**
页面中央显示一个旋转的加载圆圈（蓝色圆环），背景为浅蓝到浅绿的渐变色。

**加载失败：**
如果网络错误或结果不存在，页面中央显示红色错误提示文字，下方有"返回首页"链接按钮。

## 报告页面布局

报告页面从上到下依次显示：

| 区域 | 位置 | 说明 |
|------|------|------|
| 返回按钮 | 页面左上角 | "← 返回"文字按钮，点击回到上一页（答案速查页） |
| 报告标题与导出 | 报告卡片上方 | 左侧标题"📊 答题报告"，右侧"📥 导出报告"按钮 |
| 模块一：总览 | 报告区顶部 | 得分、正确率、对错统计 |
| 模块二：按题型 | 总览下方 | 各题型正确率柱状图 |
| 模块三：按难度 | 题型下方 | 简单/中等/困难正确率柱状图 |
| 模块四：AI 分析 | 最下方 | AI 生成的知识点分析或面试深度分析 |

页面背景为浅蓝到浅绿的渐变色（`from-sky-50 via-white to-emerald-50`），内容区最大宽度为 `max-w-4xl`。

## 模块一：总览

### 外观

白色半透明圆角卡片，带浅灰色边框。

### 标题

卡片顶部显示灰色小号大写字母标题：**"总览 · {题库名称}"**。

例如：`总览 · 前端基础知识测试`

### 数据展示

标题下方以三列网格布局展示三项核心数据：

#### 得分

- 数值以天蓝色（`text-sky-500`）大字显示（约 24px 粗体），如 **"8 / 10"**
- 斜杠后的总分以较淡的灰色显示
- 上方标签为灰色小字"得分"

#### 正确率

- 数值以翠绿色（`text-emerald-500`）大字显示（约 24px 粗体），如 **"80%"**
- 上方标签为灰色小字"正确率"
- 正确率计算规则：正确题目数 / 总题目数（未答题视为错误）

#### 对 / 错 / 未答

- 以中等大小文字（约 16px）显示：
  - `✓` 后跟正确数量
  - `✗` 后跟错误数量
  - `⊘` 后跟未答数量
- 上方标签为灰色小字"对 / 错 / 未答"

**示例展示：**

```
得分              正确率             对 / 错 / 未答
8 / 10           80%                ✓ 8  ✗ 1  ⊘ 1
```

## 模块二：按题型正确率

### 外观

白色半透明圆角卡片，带浅灰色边框。

### 标题

灰色小号大写字母标题：**"按题型"**。

### 柱状图

每行对应一种题型，共三列：

| 列 | 位置 | 内容 |
|----|------|------|
| 题型名称 | 左侧（宽约 64px） | 灰色文字，如"单选题"、"填空题" |
| 进度条 | 中间（占满剩余空间） | 浅灰底圆角条，内有彩色填充条 |
| 统计数据 | 右侧（宽约 96px） | 等宽字体，格式"正确数/总数 (正确率%)" |

**题型名称映射：**

| 英文类型 | 中文显示 |
|----------|----------|
| `single` | 单选题 |
| `multiple` | 多选题 |
| `boolean` | 判断题 |
| `fill` | 填空题 |
| `essay` | 简答题 |
| `code` | 代码题 |
| `interview` | 面试题 |

**进度条颜色规则：**

| 正确率范围 | 颜色 |
|------------|------|
| 大于等于 80% | 绿色渐变（翠绿） |
| 50% ~ 79% | 蓝色渐变（天蓝） |
| 小于 50% | 红色渐变（玫红） |

**示例展示：**

```
单选题    ████████████████████░░░░  8/10 (80%)    ← 绿色条
填空题    ██████████████░░░░░░░░  6/10 (60%)    ← 蓝色条
简答题    ██████░░░░░░░░░░░░░░░░  3/10 (30%)    ← 红色条
```

如果没有任何题型数据，显示灰色斜体文字"（无数据）"。

## 模块三：按难度正确率

### 外观

白色半透明圆角卡片，带浅灰色边框。

### 显示条件

仅当题库中有题目标注了**难度等级**（简单 / 中等 / 困难）时，此模块才会显示。

- 如果所有题目都**没有**难度标记 → 整个模块不显示
- 如果部分题目有、部分没有 → 模块正常显示，并在标题后括号注明无难度标记的题目数

### 标题

灰色小号大写字母标题：**"按难度"**。

如果存在无难度标记的题目，标题后面追加灰色文字 `(另有 X 题无难度标记)`，其中 X 为实际数量。

### 柱状图

与"按题型"模块相同的柱状图格式，但维度改为三个难度等级：

- 简单
- 中等
- 困难

每行显示该难度等级的正确数/总数 (正确率%)，进度条颜色规则相同。

## 模块四：AI 分析

系统根据题型自动判断使用哪种 AI 分析模式：

- **普通题型**：题库中包含选择题、填空题、代码题等常规题型 → 使用普通 AI 分析（5 积分）
- **面试题型**：题库中**所有题目都是面试题或简答题** → 使用面试深度分析（100 积分）

---

### 普通题型 AI 分析（5 积分）

#### 标题与按钮

白色卡片顶部显示标题：**"AI 分析 · 知识点 + 建议（扣 5 积分）"**。

如果还没有生成过报告，标题右侧显示一个 **"🔮 AI 生成报告"** 按钮：

- 蓝绿渐变背景（`from-sky-400 to-emerald-400`），白色文字
- 鼠标悬停颜色加深

#### 生成流程

**步骤一：点击生成按钮**

1. 点击"🔮 AI 生成报告"按钮。
2. 按钮文字变为 **"生成中..."**，按钮变为禁用状态（透明度降低）。

**步骤二：等待 AI 生成**

系统调用 `POST /api/ai/report` 接口，传入当前结果 ID。AI 分析答题数据后返回薄弱知识点和学习建议。

生成期间，按钮保持"生成中..."状态。

**步骤三：查看结果**

生成成功 → 按钮消失，报告内容直接显示在卡片中。如果这是首次生成（非缓存），在报告底部显示积分扣除提示。

#### 积分不足

如果当前积分不足以支付 5 积分，显示红色错误提示框（玫红背景、玫红文字）：

```
积分不足:需要 5,当前 X
```

其中 X 为当前剩余积分。此时报告不会生成，用户需要先获取积分后再重试。

#### 缓存复用机制

同一答题结果（同一个 resultId）只生成一次报告。生成后报告缓存在服务端，再次访问同一报告页时：

- 页面加载时自动从缓存读取报告内容，**无需再次点击生成按钮**
- **不会再次扣积分**
- 不显示积分扣除提示

缓存复用时的表现：进入报告页后，AI 分析卡片中直接显示已有的报告内容，按钮不出现。

#### 报告内容展示

生成成功后，卡片内从上到下显示两部分内容：

##### 1. 薄弱知识点

- 小标题："薄弱知识点"（灰色小字）
- 以**黄色标签**列表展示，每个标签为一个浅黄色（`bg-amber-50`）圆角小方块，黄色边框，黄色文字
- 示例标签：`闭包`、`原型链`、`事件循环`
- 将鼠标悬停在任意标签上时，弹出提示（`title` 属性）显示该知识点相关的题目编号，如：`相关题目: 3, 7, 12`

##### 2. 下一步建议

- 小标题："下一步建议"（灰色小字）
- 以 **Markdown 渲染**的方式展示 AI 生成的学习建议文本
- 支持 Markdown 格式（标题、列表、加粗、代码块等），由 AI 自由组织内容

##### 积分提示

报告内容最下方显示灰色小字：

```
本次扣 5 积分，剩余 X 积分
```

仅在首次生成（非缓存命中）时显示。

---

### 面试题 AI 深度分析（100 积分）

#### 触发条件

当题库中**全部题目**的类型为 `interview`（面试题）或 `essay`（简答题）时，AI 分析自动切换为面试深度分析模式。

#### 标题与按钮

白色卡片顶部显示标题：**"🤖 AI 面试深度分析（100 积分/次）"**。

如果还没有生成过报告，标题右侧显示一个 **"🔮 AI 面试分析"** 按钮：

- 紫蓝渐变背景（`from-indigo-500 to-purple-500`），白色文字
- 鼠标悬停颜色加深

#### 生成流程

与普通 AI 分析相同：

1. 点击"🔮 AI 面试分析"按钮。
2. 按钮变为"生成中..."，按钮禁用。
3. 系统调用 `POST /api/ai/interview-report` 接口（与普通分析使用不同的 API）。
4. 积分不足时显示红色错误"积分不足:需要 100,当前 X"。
5. 成功后按钮消失，报告内容展示。
6. 底部显示"本次扣 100 积分，剩余 X 积分"。

> **注意**：面试题报告**不使用缓存**，每次进入报告页都需要手动点击按钮重新生成，每次生成消耗 100 积分。

#### 报告内容展示

生成成功后，卡片内从上到下显示四个部分：

##### 1. 综合评分卡片

一个紫蓝渐变背景（`from-indigo-50 to-purple-50`）的圆角卡片，内有左右两栏：

**左侧——分数：**
- 大号数字（约 36px 粗体），如 **"85"**
- 数字下方灰色小字："/ 100 综合评分"
- 分数颜色根据得分高低变化：

| 分数范围 | 颜色 |
|----------|------|
| 大于等于 80 分 | 翠绿色（`text-emerald-600`） |
| 60 ~ 79 分 | 琥珀色（`text-amber-600`） |
| 小于 60 分 | 红色（`text-red-500`） |

**右侧——整体评价：**
- Markdown 渲染的评价文字，灰色正文
- AI 对整体表现的综合评语

##### 2. 已掌握领域 ✅

- 小标题："✅ 已掌握领域"（翠绿色加粗文字）
- 每个已掌握领域以**绿色卡片**（翠绿背景 `bg-emerald-50`，翠绿边框）展示：
  - **领域名称**（加粗，翠绿色深色文字）
  - 详细说明（翠绿色正文，小号字体）

##### 3. 薄弱领域 ⚠️

- 小标题："⚠️ 薄弱领域"（琥珀色加粗文字）
- 每个薄弱领域以**黄色卡片**（琥珀背景 `bg-amber-50`，琥珀边框）展示：
  - **领域名称**（加粗，琥珀色深色文字）
  - 详细说明（琥珀色正文，小号字体）
  - **改进建议**：蓝色左边框 + `💡` 图标开头，蓝色文字（`text-blue-700`），位于说明文字下方

##### 4. 改进计划 📋

- 小标题："📋 改进计划"（蓝色加粗文字）
- **蓝色背景卡片**（`bg-blue-50`，蓝色边框）：
  - Markdown 渲染的改进计划文本
  - 灰色正文，支持列表、段落等格式

## 导出报告

### 按钮位置

报告页面的**右上角**（标题"📊 答题报告"右侧），有一个 **"📥 导出报告"** 按钮：

- 白色背景，浅灰色边框，灰色文字
- 鼠标悬停时：浅绿背景（`bg-emerald-50`），绿色边框，绿色文字

### 导出操作

1. 点击"📥 导出报告"按钮。
2. 系统将当前报告页面上的所有内容整理为 Markdown 格式文本。
3. 浏览器自动触发文件下载。

### 导出文件

- **格式**：`.md` 文件（Markdown 格式）
- **文件名规则**：`{题库名称}_报告_{日期}.md`
  - 题库名称中的特殊字符（`\ / : * ? " < > |`）会被替换为下划线 `_`
  - 日期格式为 `YYYY-MM-DD`（如 `2026-08-08`）
  - 示例：`前端基础知识测试_报告_2026-08-08.md`

### 导出内容结构

导出文件中按顺序包含以下章节：

```
# 📊 答题报告 - {题库名称}

> 导出时间: 2026-08-08

## 一、总览
- 得分: X / Y
- 正确率: Z%
- 正确/错误/未答统计

## 二、按题型正确率
- 各题型正确率数据

## 三、按难度正确率
- 各难度等级正确率数据

## 四、AI 分析（或 AI 面试深度分析）
- 分析报告的完整文本内容
```

> **注意**：导出内容中的 AI 分析部分取决于当前页面是否已生成报告。如果尚未点击生成按钮生成 AI 报告，导出文件中该模块内容为空。

## 常见问题

### 问：为什么"按难度"模块不显示？

答：这可能是因为题库中的题目没有标注难度等级。系统只显示有难度标注的题目的统计数据。如果题目来自手动粘贴或简单格式的上传文件，通常没有难度信息。"按难度"模块只在至少有一道题标注了难度时出现。

### 问：AI 报告生成失败怎么办？

答：常见失败原因有两种：
1. **积分不足**：页面会显示红色错误提示"积分不足:需要 X,当前 Y"。请通过签到或其他方式获取积分后重试。
2. **网络或服务异常**：页面会显示"生成失败"。请检查网络连接，稍后重试。

### 问：面试题报告和普通报告有什么区别？

答：
- **普通报告**（5 积分）：输出薄弱知识点标签和下一步学习建议，适合有标准答案的客观题。
- **面试深度分析**（100 积分）：输出综合评分、领域掌握评估和改进计划，适合主观性强的面试题。系统会根据题库类型自动选择，无需手动切换。

### 问：同一份答卷可以多次查看报告吗？

答：可以。普通题型的 AI 报告会缓存，再次访问时直接显示，不会重复扣积分。面试题报告不使用缓存，每次需要手动生成，每次消耗 100 积分。

### 问：如何回到答题结果页面？

答：点击报告页面左上角的"← 返回"按钮，即可回到上一页（答案速查页面）。

## 快速参考：积分消耗一览

| 报告类型 | 消耗积分 | 缓存机制 | 触发条件 |
|----------|----------|----------|----------|
| 普通 AI 分析 | 5 积分 | 同一结果缓存复用，不重复扣费 | 题库包含非面试/非简答题型 |
| 面试深度分析 | 100 积分 | 无缓存，每次生成均扣费 | 题库全部为面试题或简答题 |
| 统计图表（模块一/二/三） | 免费 | 每次访问自动计算 | 所有报告页均有 |
| 导出报告 | 免费 | — | 随时可用 |
