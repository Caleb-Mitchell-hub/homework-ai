# 答题

## 功能说明

答题功能是系统的核心模块，用户进入题库后逐题作答，支持七种题型的输入、自动/手动判分、AI 评分、暂存进度、倒计时、历史查阅和答案速查等完整答题流程。

系统支持的七种题型：

| 题型 | 图标/标记 | 作答方式 | 判分方式 |
|------|----------|----------|----------|
| 单选题 | 蓝色标记 | 点击选项卡片（radio 单选） | 自动判分，与标准答案对比 |
| 多选题 | 紫色标记 | 点击选项卡片（checkbox 多选） | 自动判分，选项完全匹配 |
| 判断题 | 黄色标记 | 点击"正确"/"错误"大按钮（radio 单选） | 自动判分，与标准答案对比 |
| 填空题 | 绿色标记 | 文本输入框（多个答案用分号/逗号分隔） | 自动判分，逐一匹配 |
| 简答题 | 粉色标记 | 多行文本域 | 主观题，机器不判分，支持 AI 评分 |
| 代码题 | 青色标记 | 左右两栏：左栏写代码，右栏实时预览高亮 | 主观题，机器不判分 |
| 面试题 | 靛蓝色标记 | 多行文本域，有子问题时展示"面试要点"列表 | 主观题，支持 AI 评分（亮点/不足/建议） |

## 进入答题页面

### 方式一：通过上传题库进入

1. 在**上传题库页面**完成题目解析后（参考 [01-新增题库](./01-新增题库.md)），系统自动创建题库并跳转到答题页面。
2. 页面 URL 格式为 `/quiz/[题库ID]`，如 `/quiz/abc123`。

### 方式二：从首页进入已有题库

1. 登录系统后，进入首页（题库列表页）。
2. 找到目标题库卡片。
3. 点击题库卡片上的**"开始答题"**按钮（或直接点击题库卡片标题区）。
4. 页面跳转至 `/quiz/[题库ID]`，进入答题页面。

### 方式三：通过上传重复文件恢复进度

上传与之前相同内容的文件时，系统检测到已有题库后弹出提示对话框，可选择**"继续上次进度"**直接进入答题页面并恢复之前保存的答案。

## 答题页面布局

进入答题页面后，整体分为四个区域：

| 区域 | 位置 | 说明 |
|------|------|------|
| 顶部 Sticky 栏 | 页面最上方，吸顶固定 | 返回按钮、题库标题、倒计时（或"不限时"标签）、历史切换器、已答/总题数进度 |
| 时间消耗进度条 | 顶部 Sticky 栏下方（仅限时模式） | 2px 细进度条，显示已消耗时间占比 |
| 主答题区 | 页面中部 | 左侧题目卡片列表 + 右侧答题卡导航面板 |
| 底部浮动按钮栏 | 页面底部固定居中 | "置顶"、"暂存进度"、"提交答案"三个按钮 |

### 顶部 Sticky 栏详解

顶部栏在页面滚动时始终固定在屏幕顶部（`position: sticky`），从左上到右上依次显示：

- **返回按钮（←）**：浅灰色圆形按钮（`w-7 h-7`），点击跳转回首页。hover 时颜色变深、背景变白。
- **题库标题**：居中显示，最长单行截断显示完整标题在 tooltip 中。15px 字体，深灰色加粗。
- **倒计时区域**（右侧）：
  - **有限时模式**：白色圆角小卡片，内有时钟图标 + 倒计时数字（`MM:SS` 格式，超过1小时显示 `H:MM:SS`）。字体为等宽数字（`tabular-nums`），深灰色。
    - 剩余时间 **> 60 秒**：卡片白色底、灰色边框，数字深灰色，正常显示。
    - 剩余时间 **<= 60 秒**：卡片变为玫瑰红背景（`bg-rose-50`）、玫瑰红边框（`border-rose-300`），文字变红（`text-rose-600`），**带脉冲动画**（`animate-pulse`）。
  - **不限时模式**：显示灰色标签"⏱ 不限时"（浅灰底、灰色文字，11px 字体）。
- **历史切换器**：当该题库有 >=1 份已提交记录时显示。一个白色/半透明按钮，文字"📚 N 次"，点击展开下拉列表。
- **进度显示**：数字 `X / Y`（已答数/总题数，蓝色加粗数字 + 浅灰色总数），右侧附带一条微型进度条（12px 宽、2px 高、蓝绿渐变填充）。

### 时间消耗进度条

仅在设置了答题时长时显示。位于顶部 Sticky 栏正下方，是一条 2px 高的细线：

- 背景色：浅灰色（`bg-slate-200/60`），圆角
- 填充条：已消耗时间越长，填充越多（`width` 百分比实时变化）
  - 正常状态：蓝绿渐变（`from-sky-400 to-emerald-400`）
  - 剩余 <= 60 秒：变为玫瑰红渐变（`from-rose-400 to-rose-500`）
- 过渡动画：`transition-all duration-1000 ease-linear`

### 底部浮动按钮栏

固定在页面底部、水平居中的三个按钮（`fixed bottom-6 left-1/2 -translate-x-1/2`），带阴影，`z-index: 50`：

| 按钮 | 外观 | 功能 | 状态 |
|------|------|------|------|
| **置顶** | 白色/半透明背景，灰色文字，灰色边框，圆角（`rounded-xl`） | 点击后将页面主体滚动到顶部 | 始终可用，`px-4 py-3` |
| **暂存进度** | 琥珀色背景（`bg-amber-400`），白色文字，琥珀色阴影（`shadow-amber-200`） | 保存当前答题进度为草稿（status='draft'） | 提交中时禁用（透明度降低）；`px-6 py-3` |
| **提交答案** | 蓝绿渐变背景（`from-sky-400 to-emerald-400`），白色文字，蓝色阴影（`shadow-sky-200`） | 判分并提交答案（status='submitted'） | 提交中时禁用；`px-8 py-3`，文字变为"AI 评分中..."带旋转图标 |

## 题目卡片详解（QuestionCard）

每道题渲染为一张独立的白色卡片（`bg-white/80`），带对应题型的彩色边框，圆角 16px（`rounded-2xl`），卡片间距 24px（`mb-6`）。

### 卡片头部

每张卡片顶部显示：

- **题号圆圈**：蓝绿渐变色圆形徽章（`w-10 h-10`），白色粗体数字（1-based），带阴影（`shadow-sm`）。颜色统一（所有题型均蓝绿渐变）。
- **题型标签**：彩色小型徽章（`px-3 py-1 rounded-lg`），文字显示题型中文名（单选题、多选题、判断题、填空题、简答题、代码题、面试题），各题型配色如下：

| 题型 | 背景色 | 文字色 | 边框色 |
|------|--------|--------|--------|
| 单选题 | `bg-sky-50`（浅蓝） | `text-sky-600`（蓝） | `border-sky-200` |
| 多选题 | `bg-violet-50`（浅紫） | `text-violet-600`（紫） | `border-violet-200` |
| 判断题 | `bg-amber-50`（浅黄） | `text-amber-600`（琥珀） | `border-amber-200` |
| 填空题 | `bg-emerald-50`（浅绿） | `text-emerald-600`（绿） | `border-emerald-200` |
| 简答题 | `bg-pink-50`（浅粉） | `text-pink-600`（粉） | `border-pink-200` |
| 代码题 | `bg-cyan-50`（浅青） | `text-cyan-600`（青） | `border-cyan-200` |
| 面试题 | `bg-indigo-50`（浅靛蓝） | `text-indigo-600`（靛蓝） | `border-indigo-200` |

### 题目内容区

题目标题使用 **Markdown 渲染**（通过 `MarkdownView` 组件），支持加粗、列表、代码行内块、链接等 Markdown 语法。标题下方（间距 `mb-6`），左对齐显示（`text-left`）。

**特殊：非代码题但携带代码块**：如果题目题型不是"代码题"但数据中携带了 `code` 字段（如面试题附带了代码示例），会在题干下方额外显示一个语法高亮的代码块：

- 左上角标签："代码：" + 语言名称标签（青色小徽章，如 `python`、`javascript`）
- 代码块：深色背景（`bg-slate-900`），使用 Night Owl 主题的 Prism 语法高亮
- 代码以等宽字体显示，可横向滚动

### 各题型输入区域

#### 单选题

- **4 个选项卡片**（A/B/C/D），纵向排列（`space-y-3`）
- 每张选项卡片：
  - 左侧：选项字母大圆圈（`w-8 h-8`），灰色底/灰色字或蓝色底/白色字
  - 中间：选项文字（Markdown 可渲染）
  - 右侧：隐藏的 `radio` 输入框（`className="hidden"`）
- 选中状态：卡片背景变为浅蓝色（`bg-sky-50`），边框变为蓝色（`border-sky-300`），字母圆圈变为蓝色底白色字
- 未选中状态：白色背景（`bg-white`），灰色边框（`border-slate-200`），hover 时变为浅蓝底
- 点击任意一张卡片即选中该选项，自动取消其他选项

#### 多选题

- **4 个选项卡片**（A/B/C/D），纵向排列（`space-y-3`）
- 每张选项卡片：
  - 左侧：选项字母大圆圈（`w-8 h-8`），灰色底/灰色字或紫色底/白色字
  - 中间：选项文字（Markdown 可渲染）
  - 右侧：隐藏的 `checkbox` 输入框（`className="hidden"`）
- 选中状态：卡片背景变为浅紫色（`bg-violet-50`），边框变为紫色（`border-violet-300`），字母圆圈变为紫色底白色字
- 未选中状态：白色背景（`bg-white`），灰色边框（`border-slate-200`），hover 时变为浅紫底
- 可同时选中多个选项，点击已选中的选项会取消选中
- 答案以字母组合形式存储（如 `AC`、`ABD`），按字母顺序排序

#### 判断题

- **2 个大按钮**并排显示（`flex gap-4`），各占 50% 宽度（`flex-1`）
  - 左侧：**正确 ✓**（`val: 'true'`，绿色圆圈内白色勾号图标）
  - 右侧：**错误 ✗**（`val: 'false'`，灰色圆圈内白色叉号图标）
- 选中状态：卡片背景变为浅黄色（`bg-amber-50`），边框变为黄色（`border-amber-300`），圆圈变为琥珀色底白色图标
- 未选中状态：白色背景，灰色边框，hover 时淡黄色
- 点击切换选中状态（radio 单选行为）

#### 填空题

- 一个**单行文本输入框**（`<input type="text">`）
- 样式：白色背景，灰色边框（`border-slate-200`），圆角（`rounded-xl`），内边距 16px（`p-4`）
- 聚焦时边框变为绿色（`border-emerald-400`），外层亮绿色光圈（`ring-4 ring-emerald-100`）
- **placeholder 提示**：
  - 1 个填空时：`用分号或逗号分隔答案`
  - N 个填空时：`用分号或逗号分隔N个答案`
- 多个答案之间用分号（`;`）或逗号（`,`）分隔

#### 简答题

- 一个**多行文本域**（`<textarea rows={5}>`）
- 样式：白色背景，灰色边框，圆角，5 行高度，禁止手动调整大小（`resize-none`）
- 聚焦时边框变为粉色（`border-pink-400`），外层亮粉色光圈（`ring-4 ring-pink-100`）
- **placeholder 提示**：`请输入您的答案...`

#### 面试题

面试题有两部分：

**A. 面试要点区域**（有子问题时显示）：

- 浅蓝紫色背景（`bg-indigo-50/40`），蓝紫色边框（`border-indigo-100`），圆角卡片（`rounded-xl`），内边距 12px（`p-3`）
- 顶部标签："📋 面试要点"（蓝紫色文字，11px，大写字母间距）
- 下方编号列表（`<ol>`），显示每个子问题的编号和内容，列表项 13px 灰色文字
- 子问题内容同样支持 Markdown 渲染

**B. 答案输入区**：

- 一个**多行文本域**（`<textarea rows={6}>`），6 行高度
- 样式：白色背景，灰色边框，圆角，禁止手动调整大小
- 聚焦时边框变为靛蓝色（`border-indigo-400`），外层靛蓝光圈（`ring-4 ring-indigo-100`）
- **placeholder 提示**：`请写下你的思路 / 经验 / 代码示例…`

#### 代码题

代码题是输入最丰富的题型，包含三部分：

**A. 题目代码展示：**

- 左上角标签："代码：" + 语言名称青云标签（如 `python`）
- 下方深色背景代码块（`bg-slate-900`），Night Owl 主题语法高亮

**B. 输入/输出示例：**

- **输入示例**：左侧"输入："标签 + 琥珀色底代码块（`bg-amber-50`、`text-amber-700`、等宽字体）
- **输出示例**：左侧"输出："标签 + 绿色底代码块（`bg-emerald-50`、`text-emerald-700`、等宽字体）

**C. 答题区域（左右两栏布局）：**

- 上方标签："你的答案（Python代码）："
- 左右两栏（`grid grid-cols-2 gap-3`）：
  - **左栏——代码编辑器**：多行文本域（`rows={12}`），等宽字体（`font-mono`），白色背景，聚焦时青色边框（`border-cyan-400`）和光圈（`ring-4 ring-cyan-100`），placeholder "请输入Python代码..."
  - **右栏——代码预览**：带标题栏"代码预览"（灰色顶栏），下方实时语法高亮预览区，同样使用 Night Owl 主题。未输入时显示灰色提示"输入代码后预览将显示在这里"

## 答题卡导航（QuizSidebar）

位于页面右侧的固定导航面板（仅在桌面端 lg 屏幕以上显示，`hidden lg:block`），`sticky top-[120px]`，宽度 260px（`w-[260px]`），随页面滚动固定在一个合适位置。

### 布局结构

从上到下：

1. **顶部状态行**：左侧灰色小字"Status"（衬线斜体），右侧显示"已答数 / 总数 · 百分比"，已答数为蓝色粗体。

2. **细线进度条**：2px 高的蓝绿渐变进度条，显示答题完成比例（`width = 百分比%`），过渡动画 500ms（`duration-500`）。

3. **题号网格**（主体区域）：
   - 每行 5 个题号按钮（`grid grid-cols-5 gap-1.5`）
   - 每个按钮为正方形（`aspect-square rounded-md`），显示题号数字（`text-[12px] font-medium`）
   - **已答状态**：蓝色实心背景（`bg-sky-400`），白色文字，带阴影（`shadow-sm`），hover 变为深蓝（`hover:bg-sky-500`）
   - **未答状态**：浅灰背景（`bg-slate-50`），灰色文字（`text-slate-400`），灰色边框（`border border-slate-200`），hover 边框变蓝（`hover:border-sky-300`）、文字变蓝（`hover:text-sky-500`）
   - 鼠标悬停时 tooltip 显示"第 N 题 · 已答"或"第 N 题 · 未答"
   - **点击题号**：页面平滑滚动到对应题目卡片（`scrollIntoView({ behavior: 'smooth', block: 'start' })`）

4. **底部图例**：
   - 左侧：蓝色方块标记 + "已答"文字 + 灰色空心方块标记 + "未答"文字
   - 右侧：剩余未答题数（"余 N"灰色文字），全部答完时显示绿色"完成"

## 答题进度自动保存

系统会在每次答案变化时，自动将当前答题进度保存到浏览器的 **localStorage** 中：

- 存储 key：`quiz_progress_{题库ID}`
- 存储内容：`Record<string, string>` 格式的答案数据（题号 → 用户答案）
- 刷新页面、关闭标签页后重新进入，答案自动恢复
- 提交成功后或点击"重新答题"时，会清除对应缓存

## 倒计时功能

倒计时仅在题库设置了**答题时长**（`timeLimit > 0`）时启用。

### 计时规则

- 页面加载时初始化倒计时：`remainingSec = timeLimit × 60`（分钟转秒）
- 每秒递减 1（通过 `setTimeout` 每秒触发一次 `setRemainingSec(s => s - 1)`）
- 倒计时数字采用 **等宽数字**（`tabular-nums`）避免数字变化时产生抖动

### 提醒机制

| 触发条件 | 提醒内容 | 触发方式 | 附加条件 |
|----------|----------|----------|----------|
| 剩余 5 分钟 | "还剩 5 分钟" | Toast 弹窗提示 | 仅当原时长 >= 6 分钟时触发（避免一开始就弹窗） |
| 剩余 1 分钟 | "还剩 1 分钟，请注意时间" | Toast 弹窗提示 | 无附加条件 |
| 剩余 <= 60 秒 | 倒计时变红 + 脉冲动画 + 进度条变红 | 视觉变化 | 无附加条件 |
| 时间到（<= 0 秒） | "时间到，自动提交" + **自动提交答案** | Toast + 自动执行提交 | 跳过命名对话框，直接提交 |

每个提醒只触发一次（通过 `warned5minRef`、`warned1minRef`、`autoSubmittedRef` 防止重复）。

### 时间到自动提交

1. Toast 显示"时间到，自动提交"
2. 自动调用 `doSubmit(true)`（`skipDialog = true`，跳过命名对话框）
3. 提交逻辑与手动点击"提交答案"相同：判分 → 保存到后端 → 跳转到答案速查视图

## 历史切换器（HistorySwitcher）

当该题库有至少 1 份已提交记录（`status='submitted'`）时，在顶部栏倒计时右侧显示一个下拉按钮。

### 外观与交互

- **按钮**：白色半透明背景（`bg-white/80`），灰色边框，文字"📚 N 次"（N 为已提交记录总数），灰色文字（`text-[12px]`），圆角（`rounded-md`）
- **点击按钮**：展开下拉列表（`absolute` 定位在按钮右下方）
- **下拉列表**：白色背景，灰色边框，圆角卡片（`rounded-lg`），阴影（`shadow-lg`），最大高度 320px（`max-h-80`），超出可滚动
  - 每条记录一行按钮：上行为记录名称（`text-[13px] font-medium`），下行为提交日期时间（zh-CN 格式）+ 分数（`得分/总分`，等宽字体），灰色文字
  - 记录按提交时间**从新到旧**排序
  - 鼠标 hover 行变为浅灰背景（`hover:bg-slate-50`）
- **点击某条记录**：加载该记录的答案数据 → 切换到答案速查视图（`setSubmitted(true)` + `setResult(target)`）
- **点击下拉列表外部区域**：关闭下拉列表

## 暂存进度

"暂存进度"功能用于在答题过程中随时保存进度，稍后继续答题。

### 操作流程

#### 情况 A：已有名称 + 分类（跳过对话框）

触发条件：题库的 `quizName` 和 `selectedCategoryId` 都已确定（如从之前的草稿恢复，或从重复上传恢复时自动填入）。

1. 点击底部**"暂存进度"**按钮（琥珀色，`bg-amber-400`）。
2. 系统直接执行暂存操作（不弹出对话框），调用 `POST /api/results`，`status='draft'`。
3. Toast 提示"进度已暂存"。

#### 情况 B：缺少名称或分类（弹出对话框）

触发条件：`quizName` 为空或 `selectedCategoryId` 为 null。

1. 点击底部**"暂存进度"**琥珀色按钮。
2. 弹出**暂存进度对话框**：
   - 页面背景变暗（半透明黑色遮罩 `bg-slate-900/40 backdrop-blur-sm`）
   - 对话框居中显示，白色背景，圆角（`rounded-2xl`），最大宽度 `max-w-md`
   - 标题："**暂存答题进度**"（深灰色粗体）
   - **名称输入框**：白色输入框，浅灰背景，灰色边框，聚焦时蓝色边框和光圈
     - **placeholder**：自动填充为 `draftName`（之前的记录名）或 `{题库标题}_{当前日期}`
     - 用户可直接使用默认值或输入自定义名称
   - **分类选择器**：标签"保存到分类"（灰色 12px），下方 `CategorySelect` 下拉组件
   - **操作按钮**（底部并排）：
     - 左侧：**"取消"**按钮（灰色背景 `bg-slate-100`，灰色文字），点击关闭对话框、清空名称
     - 右侧：**"确认暂存"**按钮（琥珀色背景 `bg-amber-400`，白色文字），点击执行暂存
3. 点击"确认暂存"后，系统调用 `POST /api/results`（`status='draft'`），Toast 提示"进度已暂存"。
4. 暂存成功后，对话框关闭，`draftName` 更新为该记录名称。

### 暂存后可继续答题

暂存后页面不发生跳转，仍在当前答题页面，用户可以继续修改答案。下次重新进入该题库时，系统自动恢复到上次暂存的答案状态。

## 提交答案

"提交答案"是答题流程的最终步骤，会将答案判分并保存为已提交记录。

### 操作流程

#### 情况 A：已有名称 + 分类（跳过对话框）

同暂存逻辑，直接执行提交。

#### 情况 B：缺少名称或分类（弹出对话框）

1. 点击底部**"提交答案"**蓝绿渐变按钮。
2. 弹出**确认提交对话框**：
   - 标题变为："**确认提交答案**"
   - 名称输入框和分类选择器同上
   - 操作按钮：
     - 左侧：**"取消"**按钮（灰色）
     - 右侧：**"确认提交"**按钮（蓝绿渐变 `from-sky-400 to-emerald-400`，白色文字）
3. 点击"确认提交"后，执行以下流程。

### 提交执行流程

1. **按钮状态变化**：提交过程中按钮禁用（`disabled`），文字变为"AI 评分中..."，带旋转动画的 svg 图标。

2. **本地判分**（`gradeQuiz`）：
   - 收集用户所有答案（未作答的题答案为空字符串 `''`）
   - 与标准答案比对：
     - 单选/多选/判断/填空：本地自动判分，判定正确/错误
     - 简答/代码/面试：机器不判分，标记为"主观"（不参与正确/错误判断），score 计为 0
   - 计算总分和得分

3. **保存到后端**：调用 `POST /api/results`，`status='submitted'`，携带 `quizId`、`name`、`score`、`totalScore`、`results` 等数据。

4. **提交成功后**：
   - 将当前题库 ID 存入 localStorage（`currentQuizId`），供首页定位
   - 清除答题进度缓存（`localStorage.removeItem(quiz_progress_{quizId})`）
   - 如果用户选择了分类，将结果归类到对应分类
   - 清空本地名称状态
   - 页面切换到**答案速查视图**（`setSubmitted(true)` + `setResult(data.result)`）

5. **自动 AI 评分**：提交后自动对结果中所有**未评分的面试题和简答题**逐题调用 AI 评分接口（`POST /api/ai/grade-interview`），不阻塞页面浏览。评分结果实时更新到 `result` 状态中（亮点/不足/建议出现在对应的题目卡片中）。

### 防重复提交

- 使用 `submittingRef`（ref 锁）防止异步操作期间重复触发
- 提交按钮在 `isSubmitting` 为 true 时禁用（`disabled:opacity-50`）
- 暂存和提交互斥：暂存中不可提交，提交中不可暂存

## 重新答题

点击"重新答题"按钮后，系统执行以下操作：

1. 清空所有答案（`setAnswers({})`）
2. 退出答案速查视图（`setSubmitted(false)`），回到答题界面
3. 清空提交结果（`setResult(null)`）
4. **重置倒计时**：如果题库设置了时长，倒计时恢复到初始值（`timeLimit × 60` 秒）
5. 重置自动提交标记（`autoSubmittedRef.current = false`）
6. 清除 localStorage 中的答题进度缓存

重新答题后不会影响之前的已提交记录（之前的记录仍然可以在历史切换器中查看）。

## 特殊情况

### 情况一：页面刷新或关闭后恢复

刷新页面或关闭标签页后重新进入同一题库：

1. 系统从后端加载该题库的所有结果记录（`GET /api/results?quizId=xxx`）
2. 优先查找 `status='draft'` 的草稿记录；无草稿则取最新的已提交记录
3. 恢复答案到答题界面、恢复名称（`defaultName`）、恢复分类（`defaultCategoryId`）
4. 同时 localStorage 中的进度缓存也可作为补充恢复来源

### 情况二：答题中返回首页

点击顶部返回按钮（←）或浏览器后退键：

- 已填写的答案自动保存在 localStorage 中
- 下次进入该题库时，答案将从 localStorage 恢复（前提是没有更新的草稿记录）

### 情况三：超时自动提交

计时归零时系统自动执行提交，与手动提交的区别：

- 跳过命名对话框（`skipDialog = true`），直接使用以下名称优先级：`quizName` > `draftName` > `{题库标题}_{当前日期}`
- 分类使用当前已选中的 `selectedCategoryId`（可能为 null，即未分类）

### 情况四：多次提交同一题库

- 每次提交都会创建一条新的已提交记录
- 历史切换器中可查看所有历史答卷
- 重新答题后再次提交，不会覆盖之前的记录
